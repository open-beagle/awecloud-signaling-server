# 文档编写规范

## 设计文档 (`docs/`)

设计文档用于描述架构、流程、方案，**禁止包含源代码**。

### 允许的内容

- 文字描述和概述
- TXT 流程图（ASCII art）
- 表格对比
- 数据模型字段说明（文字形式）
- API 路径和参数说明（文字形式）
- 配置示例（TOML/JSON/YAML）

### 禁止的内容

- Go/TypeScript/Python 等源代码
- 代码片段（即使是伪代码也应避免）
- 函数实现

### 描述代码逻辑的正确方式

1. **文字概述**：用自然语言描述逻辑
2. **TXT 流程图**：用 ASCII 绘制流程

示例 - 错误的写法：

```
// 不要这样写
func (s *Service) Process() {
    data := s.fetch()
    result := s.transform(data)
    s.save(result)
}
```

示例 - 正确的写法：

```
处理流程：
1. 从数据源获取数据
2. 转换数据格式
3. 保存处理结果

┌─────────┐    ┌───────────┐    ┌─────────┐
│  获取   │───▶│   转换    │───▶│  保存   │
└─────────┘    └───────────┘    └─────────┘
```

## 临时文档 (`.tmp/`)

`.tmp/` 目录用于临时分析、学习笔记，可以包含代码片段用于学习参考，但不应作为正式文档。

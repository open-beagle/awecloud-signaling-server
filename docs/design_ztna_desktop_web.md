# Desktop Web 界面设计

## 1. 概述

Desktop 客户端 Web 界面（Wails 内嵌）提供三个核心页面：

| 序号 | 页面     | 路由      | 域名 type | 说明                           |
| ---- | -------- | --------- | --------- | ------------------------------ |
| 1    | 我的服务 | /services | k8ssvc    | K8S Service 列表，多端口支持   |
| 2    | 我的主机 | /hosts    | ssh       | SSH 主机列表，一键复制连接命令 |
| 3    | 我的K8S  | /k8s      | k8sapi    | 可管理的 K8S 集群列表          |

数据来源：Desktop 登录后通过 gRPC 从 Server 获取当前用户有权访问的域名列表。

## 2. 数据分类规则

域名注册表中的记录按 type 字段一对一映射到三个页面：

| 域名 type | 归属页面 |
| --------- | -------- |
| k8ssvc    | 我的服务 |
| ssh       | 我的主机 |
| k8sapi    | 我的K8S  |

## 3. 我的服务

### 3.1 功能定位

展示用户有权访问的 K8S Service 列表，支持多端口展示。

### 3.2 列表展示

卡片式平铺布局：

```
┌──────────────────────────────────────────────────────────┐
│  我的服务                                                │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─────────────────────────────────────────────────┐     │
│  │  ● postgres.yygl.beijing.beagle                 │     │
│  │  端口：5432, 9187                               │     │
│  └─────────────────────────────────────────────────┘     │
│                                                          │
│  ┌─────────────────────────────────────────────────┐     │
│  │  ● mysql.yygl.beijing.beagle                    │     │
│  │  端口：3306                                     │     │
│  └─────────────────────────────────────────────────┘     │
│                                                          │
│  ┌─────────────────────────────────────────────────┐     │
│  │  ● redis.cache.beijing.beagle                   │     │
│  │  端口：6379                                     │     │
│  └─────────────────────────────────────────────────┘     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 3.3 列表字段

| 字段     | 来源                            | 说明                            |
| -------- | ------------------------------- | ------------------------------- |
| 服务域名 | domain 字段                     | 如 postgres.yygl.beijing.beagle |
| 服务端口 | service_ports 字段（JSON 数组） | 如 [5432, 9187]                 |
| 服务状态 | status 字段                     | 在线（●）/ 离线（○）            |

## 4. 我的主机

### 4.1 功能定位

展示用户有权访问的所有 SSH 主机，提供连接命令复制。

### 4.2 列表展示

卡片式平铺布局，一台主机一张卡片，卡片内展示所有可用用户：

```
┌──────────────────────────────────────────────────────┐
│  我的主机                                            │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌─────────────────────────────────────────────┐     │
│  │  ● beagle-242.beijing.beagle                │     │
│  │  root [复制]   deploy [复制]                 │     │
│  └─────────────────────────────────────────────┘     │
│                                                      │
│  ┌─────────────────────────────────────────────┐     │
│  │  ○ beagle-002.neimeng.beagle                │     │
│  │  root [复制]                                 │     │
│  └─────────────────────────────────────────────┘     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

复制按钮点击后复制完整命令：ssh {user}@{domain}

### 4.3 列表字段

| 字段     | 来源           | 说明                                      |
| -------- | -------------- | ----------------------------------------- |
| 主机域名 | domain 字段    | 如 beagle-242.beijing.beagle              |
| 用户列表 | ssh_users 字段 | 如 root、deploy，每个用户一个 [复制] 按钮 |
| 主机状态 | status 字段    | 在线（●）/ 离线（○）                      |

## 5. 我的K8S

### 5.1 功能定位

展示用户可管理的 K8S 集群列表，提供 kubeconfig 生成和复制。

### 5.2 列表展示

卡片式平铺布局，点击 [复制] 复制该集群的 kubeconfig：

```
┌──────────────────────────────────────────────────────────┐
│  我的K8S                                    [复制全部]   │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─────────────────────────────────────────────────┐     │
│  │  ● kubernetes.beijing.beagle            [复制]  │     │
│  └─────────────────────────────────────────────────┘     │
│                                                          │
│  ┌─────────────────────────────────────────────────┐     │
│  │  ○ kubernetes.neimeng.beagle            [复制]  │     │
│  └─────────────────────────────────────────────────┘     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 5.3 列表字段

| 字段     | 来源        | 说明                         |
| -------- | ----------- | ---------------------------- |
| 集群域名 | domain 字段 | 如 kubernetes.beijing.beagle |
| 集群状态 | status 字段 | 在线（●）/ 离线（○）         |

点击卡片进入集群详情页，显示该集群的 kubeconfig 文本内容：

```

│  │     insecure-skip-tls-verify: true               │    │
│  │ contexts:                                        │    │
│  │ - name: beijing                                  │    │
│  │   context:                                       │    │
│  │     cluster: beijing                             │    │

│  │ current-context: beijing                         │    │
│  │ users:                                           │    │

│  │   user:                                          │    │
```

## 6. 前端设计规范

### 6.1 卡片式设计

所有页面统一采用卡片式布局，每个服务/主机/集群为一张卡片。

#### 卡片结构

```
┌─────────────────────────────────────────────────┐
│  ● 状态指示灯    标题（域名）          [操作区] │
│  描述信息 / 端口列表 / 连接命令                 │
└─────────────────────────────────────────────────┘
```

#### 三个页面的卡片样式

我的服务（k8ssvc）：

```
┌─────────────────────────────────────────────────┐
│  ● postgres.yygl.beijing.beagle                 │
│  端口：5432, 9187                               │
└─────────────────────────────────────────────────┘
```

我的主机（ssh）：

```
┌─────────────────────────────────────────────────┐
│  ● beagle-242.beijing.beagle                    │
│  root [复制]   deploy [复制]                     │
└─────────────────────────────────────────────────┘
```

我的K8S（k8sapi）：

```
┌─────────────────────────────────────────────────┐
│  ● kubernetes.beijing.beagle            [复制]  │
└─────────────────────────────────────────────────┘
```

### 6.2 状态指示

| 状态 | 指示灯 | 颜色 |
| ---- | ------ | ---- |
| 在线 | ●      | 绿色 |
| 离线 | ○      | 灰色 |

### 6.3 交互规范

- 复制按钮：点击后复制连接信息到剪贴板，显示"已复制"提示（1.5 秒后消失）
- 离线卡片：降低透明度（opacity: 0.6），操作按钮仍可用（复制命令）
- 空状态：页面无数据时显示居中提示"暂无可用的 xxx"

## 7. 界面布局设计

### 7.1 整体布局结构

Desktop 界面只有两层：

```
┌────────────────────────────────────────────────────────────┐
│  顶部导航区（Logo + 状态 + 菜单）                           │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  内容区域（当前页面内容）                                   │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 7.2 顶部导航区

单行布局，包含所有导航和状态信息。

布局说明：

- 左侧：Logo 图标 + "信令桌面" 文字 + gRPC 状态指示器 + Tunnel 状态指示器
- 右侧：功能菜单（我的服务、我的主机、我的K8S）+ 用户下拉菜单

状态指示器：

- gRPC 状态：显示连接状态（已连接/未连接/重连中），Tooltip 显示详细信息
- Tunnel 状态：显示隧道 IP 或连接状态，点击可手动重连

用户下拉菜单包含：用户信息、我的设备、查看日志、注销、切换用户

### 7.3 内容区域

占据剩余空间，直接显示卡片列表，无需页面标题。

### 7.4 导航结构

```
Desktop 主界面
  │
  ├── 顶部导航区（单行，包含所有导航元素）
  │   ├── 左侧：Logo + 连接状态
  │   └── 右侧：功能菜单 + 用户菜单
  │
  └── 内容区域
      ├── /services  — 我的服务（K8S Service 列表）
      ├── /hosts     — 我的主机（SSH 主机列表）
      └── /k8s       — 我的K8S（K8S 集群列表）
```

### 7.5 响应式设计

- 窗口最小宽度：800px
- 窗口最小高度：600px
- 卡片网格：自适应列数，最小卡片宽度 280px
- 小于 1024px 时，状态文字可隐藏，仅保留指示灯

## 8. 数据获取

```
Desktop 启动
  │
  ├─→ 登录认证（Logto OAuth）
  │
  ├─→ gRPC: GetDomainList(user_id)
  │     返回当前用户有权访问的所有域名记录
  │
  ├─→ 按 type 分类到三个页面
  │     k8ssvc → 我的服务
  │     ssh    → 我的主机
  │     k8sapi → 我的K8S
  │
  └─→ 定时刷新（轮询间隔可配置，默认 30 秒）
```

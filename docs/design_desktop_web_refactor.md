# Desktop Web 重构方案

> 本文档描述 Desktop 客户端 Web 界面的重构方案，参考 Server Web 重构原则。

## 1. 重构核心原则

### 1.1 开发原则

| 原则         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 禁止向后兼容 | 当前处于 v0.2 MVP 阶段，不考虑向后兼容，使用新数据库开发 |
| 禁止单元测试 | 功能验证由人工核验完成，不编写单元测试                   |

### 1.2 对象一致原则

与 Server 保持一致，使用统一的概念模型。

| Headscale 概念 | 重构后概念    | 说明                                   |
| -------------- | ------------- | -------------------------------------- |
| User           | User（用户）  | Agent 和 Client 都是用户，只是角色不同 |
| Node           | Node（设备）  | Agent 设备、Desktop 设备统一管理       |
| Group          | Group（分组） | 用户分组，用于批量授权                 |
| ACL            | ACL（授权）   | 统一的访问控制管理                     |

登录模式说明：

| 模式     | 触发条件                   | 界面表现                               |
| -------- | -------------------------- | -------------------------------------- |
| 完整登录 | 首次登录或清除凭据后       | 显示完整表单，所有字段可编辑           |

| 离线模式 | 服务器不可达               | 显示离线提示，提供重连和切换账号按钮   |

## 10. 与 Server 的数据交互

Desktop 客户端通过 gRPC 与 Server 通信，获取以下数据：

| 数据类型   | 接口                  | 说明                        |
| ---------- | --------------------- | --------------------------- |
| 已授权服务 | GetAuthorizedServices | 获取用户已授权的所有服务    |
| 已授权主机 | GetAuthorizedHosts    | 获取用户已授权的所有主机    |
| 主机服务   | GetHostServices       | 获取指定主机下的服务        |
| 我的设备   | GetMyDevices          | 获取用户的所有 Desktop 设备 |
| 操作日志   | GetMyLogs             | 获取用户的操作日志          |
| 服务状态   | GetServiceStatus      | 实时获取服务可用状态        |

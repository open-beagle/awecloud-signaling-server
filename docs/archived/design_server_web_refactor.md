# Server Web 重构方案

> 本文档描述 Server Web 管理界面的重构方案，核心原则是与 Headscale 元素保持一致。

## 1. 重构核心原则

### 1.1 开发原则

| 原则         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 禁止向后兼容 | 当前处于 v0.2 MVP 阶段，不考虑向后兼容，使用新数据库开发 |
| 禁止单元测试 | 功能验证由人工核验完成，不编写单元测试                   |

### 1.2 对象一致原则

将现有的 Agent、Client 统一抽象为 **User（用户）**，设备信息独立管理为 **Node（节点）**。

| Headscale 概念 | 重构后概念    | 说明                                   |
| -------------- | ------------- | -------------------------------------- |
| User           | User（用户）  | Agent 和 Client 都是用户，只是角色不同 |
| Node           | Node（设备）  | Agent 设备、Desktop 设备统一管理       |
| Group          | Group（分组） | 用户分组，用于批量授权                 |
| ACL            | ACL（授权）   | 统一的访问控制管理                     |

## 2. 新菜单结构

```txt
├── 用户管理 (Users)
│   └── 用户列表、详情
├── 设备管理 (Nodes)
│   └── 设备列表、详情
├── 分组管理 (Groups)
│   └── 分组列表、成员管理
├── 授权管理 (ACL)
│   ├── 服务授权
│   ├── 用户授权
│   ├── 分组授权
│   └── SSH 授权
├── 隧道管理 (Tunnel) [不变]
│   ├── User 管理
│   ├── Node 管理
│   └── ACL 管理
├── 审计日志 (Audit Logs) [不变]
└── 系统配置 (System Config) [不变]
```

## 3. 用户管理 (Users)

### 3.1 设计说明

- Agent 和 Client 统一为 User
- 通过 `role` 字段区分：`agent`（代理）、`client`（客户端）
- 一个 User 可以拥有多个 Node（设备）

- 设备信息独立管理，不再嵌套在 Agent/Client 详情中
- 统一管理 Agent 设备和 Desktop 设备
- 通过 `type` 字段区分：`agent`（代理设备）、`desktop`（桌面设备）

## 6. 授权管理 (ACL)

### 6.1 设计说明

统一的授权管理入口，包含四种授权类型：

| 授权类型 | 说明                                  | 授权对象      |
| -------- | ------------------------------------- | ------------- |
| 服务授权 | 授权访问某个 Agent 的特定服务（端口） | +用户 / +分组 |
| 用户授权 | 授权访问某个 User(Agent) 的所有端口   | +用户 / +分组 |
| 分组授权 | 授权访问某个 Group 标记的所有端口     | +用户 / +分组 |
| SSH授权  | SSH 访问授权管理                      | +用户 / +分组 |

### 6.2 授权弹窗设计

授权弹窗需要支持大规模数据（用户/分组可能有 100+ 条），设计原则：

- 支持分页（每页 10 条）
- 支持搜索（按名称/别名模糊搜索）
- 支持多选（一次授权多个用户/分组）
- 已授权的项不显示在列表中

## 11. ACL 同步到 Headscale

授权变更后，需要同步生成 Headscale ACL 规则。

### 11.1 ACL 规则生成逻辑

```txt
┌─────────────────┐
│  授权变更事件   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  收集所有授权   │
│  - 服务授权     │
│  - 用户授权     │
│  - 分组授权     │
│  - SSH 授权     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  展开分组成员   │
│  生成最终规则   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  同步到 Headscale│
└─────────────────┘
```

### 11.2 规则优先级

1. 服务授权：精确到 IP:Port
2. 用户授权：某 Agent 的 IP:\*
3. 分组授权：分组内所有 Agent 的 IP:\*
4. SSH 授权：IP:22

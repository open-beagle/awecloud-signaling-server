# 隧道管理设计

> 本文档描述 Server Web 管理界面中的隧道管理功能，用于查看和管理 Headscale 中的 User、Node 和 ACL 数据。

## 1. 概述

### 1.1 功能目标

提供管理员直接查看和管理 Headscale 底层数据的能力：

| 功能模块  | 说明                                       |
| --------- | ------------------------------------------ |
| User 管理 | 查看、编辑、删除 Headscale User            |
| Node 管理 | 查看、编辑、删除 Headscale Node，管理 Tags |
| ACL 管理  | 查看、编辑 Headscale ACL Policy            |

### 1.2 与现有功能的关系

| 现有功能    | 对应 Headscale 实体 | 说明                                       |
| ----------- | ------------------- | ------------------------------------------ |
| Agent 管理  | User + Node         | Agent 创建时自动创建 User，注册后创建 Node |
| Client 管理 | User                | Client 创建时自动创建 User                 |
| Desktop     | Node                | Desktop 登录后创建 Node                    |
| 服务授权    | ACL Policy          | 授权变更时自动同步 ACL                     |

隧道管理提供底层数据的直接访问，用于：

- 排查问题：查看 Headscale 实际状态
- 数据清理：删除孤立的 User/Node
- 高级配置：手动调整 ACL 规则

### 1.3 菜单结构

```txt
├── 代理管理 (Agents)
├── 服务管理 (Services)
├── 客户管理 (Clients)
├── 分组管理 (Groups)
├── 隧道管理 (Tunnel)          ← 新增
│   ├── User 管理
│   ├── Node 管理
│   └── ACL 管理
├── 审计日志 (Audit Logs)
└── 系统配置 (System Config)
```

```txt
│  ID      名称                  显示名称      类型      关联实体      Node数    创建时间        操作             │

│  2       agent-shanghai       上海机房      Agent     shanghai      1         2025-01-02     [编辑][删除]      │
│  3       client-zhangsan      张三          Client    zhangsan      3         2025-01-03     [编辑][删除]      │

```

页面模型：

| 字段     | 来源      | 获取方式                                   | 展示类型     |
| -------- | --------- | ------------------------------------------ | ------------ |
| ID       | Headscale | ListUsers API                              | 文本         |
| 名称     | Headscale | user.name                                  | 文本         |
| 显示名称 | Headscale | user.display_name                          | 文本         |
| 类型     | 计算字段  | 根据 name 前缀判断（agent-/client-/其他）  | 标签         |
| 关联实体 | 计算字段  | 去除前缀后的名称，查询本地 DB 验证是否存在 | 文本/链接    |
| Node 数  | Headscale | COUNT(nodes WHERE user_id=?)               | 数字，可点击 |
| 创建时间 | Headscale | user.created_at                            | 日期时间     |

类型筛选选项：

| 值     | 说明                           |
| ------ | ------------------------------ |
| all    | 所有类型                       |
| agent  | Agent（name 以 agent- 开头）   |
| client | Client（name 以 client- 开头） |
| orphan | 孤立（无法匹配本地实体）       |

## 6. API 设计

### 6.1 User 管理 API

#### 获取 User 列表

| 项目 | 内容                           |
| ---- | ------------------------------ |
| 路径 | GET /api/v1/admin/tunnel/users |
| 认证 | 需要管理员 JWT                 |

查询参数：

| 参数   | 类型   | 必填 | 说明                                    |
| ------ | ------ | ---- | --------------------------------------- |
| type   | string | 否   | 类型筛选：agent/client/orphan/all       |
| search | string | 否   | 搜索关键词（匹配 name 或 display_name） |
| page   | int    | 否   | 页码，默认 1                            |
| size   | int    | 否   | 每页数量，默认 20                       |

响应模型 TunnelUserListItem[]：

| 字段          | 类型   | 说明         | 数据来源                        |
| ------------- | ------ | ------------ | ------------------------------- |
| id            | uint64 | User ID      | Headscale user.id               |
| name          | string | User 名称    | Headscale user.name             |
| display_name  | string | 显示名称     | Headscale user.display_name     |
| type          | string | 类型         | 计算字段（agent/client/orphan） |
| linked_entity | string | 关联实体名称 | 本地 DB 查询                    |
| linked_id     | uint64 | 关联实体 ID  | 本地 DB 查询                    |
| node_count    | int    | Node 数量    | Headscale ListNodes 统计        |
| created_at    | string | 创建时间     | Headscale user.created_at       |

#### 获取 User 详情

| 项目 | 内容                               |
| ---- | ---------------------------------- |
| 路径 | GET /api/v1/admin/tunnel/users/:id |
| 认证 | 需要管理员 JWT                     |

响应模型 TunnelUserDetail：

| 字段          | 类型   | 说明         | 数据来源                    |
| ------------- | ------ | ------------ | --------------------------- |
| id            | uint64 | User ID      | Headscale user.id           |
| name          | string | User 名称    | Headscale user.name         |
| display_name  | string | 显示名称     | Headscale user.display_name |
| email         | string | 邮箱         | Headscale user.email        |
| type          | string | 类型         | 计算字段                    |
| linked_entity | string | 关联实体名称 | 本地 DB 查询                |
| linked_id     | uint64 | 关联实体 ID  | 本地 DB 查询                |
| created_at    | string | 创建时间     | Headscale user.created_at   |

#### 更新 User

| 项目 | 内容                               |
| ---- | ---------------------------------- |
| 路径 | PUT /api/v1/admin/tunnel/users/:id |
| 认证 | 需要管理员 JWT                     |

请求字段：

| 字段         | 类型   | 必填 | 说明     |
| ------------ | ------ | ---- | -------- |
| display_name | string | 否   | 显示名称 |

业务流程：

```txt
┌─────────────────────────────────────────────────────────────┐
```

## 7. 数据同步策略

### 7.1 本地与 Headscale 数据关系

| 本地实体 | Headscale 实体 | 关联方式                                    |
| -------- | -------------- | ------------------------------------------- |
| Agent    | User + Node    | agent.id = user.id, agent.node_id = node.id |
| Client   | User           | client.id = user.id                         |
| Desktop  | Node           | desktop.id = node.id                        |

### 7.2 孤立数据处理

孤立数据定义：

| 类型      | 定义                                      |
| --------- | ----------------------------------------- |
| 孤立 User | Headscale User 在本地无对应 Agent/Client  |
| 孤立 Node | Headscale Node 在本地无对应 Agent/Desktop |

处理建议：

- 孤立数据在列表中标记为"未知"类型
- 管理员可手动删除孤立数据
- 提供批量清理孤立数据的功能（可选）

### 7.3 数据一致性

| 场景                | 处理方式                            |
| ------------------- | ----------------------------------- |
| 本地删除 Agent      | 自动删除 Headscale User 和 Node     |
| 本地删除 Client     | 自动删除 Headscale User 和所有 Node |
| 本地删除 Desktop    | 自动删除 Headscale Node             |
| Headscale 删除 User | 同步删除本地 Agent/Client（如关联） |
| Headscale 删除 Node | 同步删除本地 Desktop（如关联）      |
| 手动修改 Tags       | 可能导致与本地分组不一致，显示警告  |
| 手动修改 ACL        | 可能导致与本地授权不一致，显示警告  |

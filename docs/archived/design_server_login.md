# Server Web 登录设计

> 本文档描述 Server Web 管理端的登录设计，基于 Logto + 钉钉实现管理员 SSO 登录。

## 1. 设计概述

### 2.2 路由配置

## 3. 后端实现

### 3.1 API 接口

| 接口               | 方法 | 说明                 |
| ------------------ | ---- | -------------------- |
| /api/auth/login    | GET  | 生成授权 URL，重定向 |
| /api/auth/callback | GET  | 处理回调，换取 Token |
| /api/auth/logout   | POST | 退出登录             |
| /api/auth/me       | GET  | 获取当前用户信息     |
| /api/auth/refresh  | POST | 刷新 Token           |

### 3.2 授权请求参数

| 参数                  | 说明                 |
| --------------------- | -------------------- |
| response_type         | code                 |
| client_id             | Logto 应用 ID        |
| redirect_uri          | 回调地址             |
| scope                 | openid profile email |
| state                 | 随机字符串，防 CSRF  |
| code_challenge        | PKCE 挑战码          |
| code_challenge_method | S256                 |

### 3.3 回调处理流程

```txt
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                                    回调处理流程                                          │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│  1. 验证 state 参数                                                                     │
│     - 与会话中保存的 state 比对                                                         │
│     - 不一致则拒绝                                                                      │
│                                                                                         │
│  2. 使用 code 换取 Token                                                                │
│     - POST /oidc/token                                                                  │
│     - 携带 code, client_id, client_secret, redirect_uri, code_verifier                 │
│                                                                                         │
│  3. 验证 id_token                                                                       │
│     - 验证签名                                                                          │
│     - 验证 iss, aud, exp, nonce                                                         │
│                                                                                         │
│  4. 查询或创建用户                                                                      │
│     - 根据 sub 查询 user 表                                                             │
│     - 不存在则创建，role = admin                                                        │
│                                                                                         │
│  5. 创建会话                                                                            │
│     - 生成 session_id                                                                   │
│     - 存储 access_token, refresh_token                                                  │
│     - 设置 HttpOnly Cookie                                                              │
│                                                                                         │
│  6. 重定向到首页                                                                        │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 3.4 用户同步

首次登录时自动创建用户：

| id_token 字段 | user 表字段 | 说明               |
| ------------- | ----------- | ------------------ |
| sub           | logto_id    | Logto 用户唯一标识 |
| email         | email       | 邮箱               |
| name          | name        | 用户名             |
| -             | role        | 固定为 admin       |
| -             | alias       | 默认与 name 相同   |

## 4. 会话管理

### 4.1 会话存储

| 存储位置   | 内容                           |
| ---------- | ------------------------------ |
| Cookie     | session_id（HttpOnly, Secure） |
| 内存/Redis | session_id → 用户信息, Token   |

### 4.2 会话有效期

| 配置项          | 默认值  | 说明         |
| --------------- | ------- | ------------ |
| session_timeout | 24 小时 | 会话超时时间 |
| idle_timeout    | 2 小时  | 空闲超时时间 |

### 4.3 退出登录

```txt
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                                    退出登录流程                                          │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│  1. 清除本地会话                                                                        │
│     - 删除 session 数据                                                                 │
│     - 清除 Cookie                                                                       │
│                                                                                         │
│  2. 调用 Logto 退出接口（可选）                                                         │
│     - 重定向到 /oidc/session/end                                                        │
│     - 实现 SSO 单点退出                                                                 │
│                                                                                         │
│  3. 重定向到登录页                                                                      │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

## 5. 中间件设计

### 5.1 认证中间件

```txt
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                                    认证中间件流程                                        │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│  1. 检查 Cookie 中的 session_id                                                         │
│     - 不存在 → 返回 401                                                                 │
│                                                                                         │
│  2. 查询会话数据                                                                        │
│     - 不存在或已过期 → 返回 401                                                         │
│                                                                                         │
│  3. 检查 access_token 是否过期                                                          │
│     - 过期 → 尝试刷新                                                                   │
│     - 刷新失败 → 返回 401                                                               │
│                                                                                         │
│  4. 将用户信息注入请求上下文                                                            │
│                                                                                         │
│  5. 继续处理请求                                                                        │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 公开路由

以下路由不需要认证：

| 路由         | 说明         |
| ------------ | ------------ |
| /api/auth/\* | 认证相关接口 |
| /api/health  | 健康检查     |
| /api/version | 版本信息     |

## 6. 配置项

### 6.1 Server 配置

| 配置项             | 说明           | 示例                                |
| ------------------ | -------------- | ----------------------------------- |
| logto.endpoint     | Logto 服务地址 | https://logto.example.com           |
| logto.app_id       | 应用 ID        | xxx                                 |
| logto.app_secret   | 应用密钥       | xxx                                 |
| logto.redirect_uri | 回调地址       | https://server.example.com/callback |
| logto.scopes       | 请求的权限范围 | openid profile email                |

### 6.2 配置示例

```toml
[logto]
endpoint = "https://logto.example.com"
app_id = "your-app-id"
app_secret = "your-app-secret"
redirect_uri = "https://server.example.com/callback"
scopes = ["openid", "profile", "email"]
```

## 7. 错误处理

| 错误场景       | 处理方式                   |
| -------------- | -------------------------- |
| state 不匹配   | 返回错误页，提示重新登录   |
| code 换取失败  | 返回错误页，显示错误信息   |
| Token 验证失败 | 返回错误页，提示重新登录   |
| 用户创建失败   | 返回错误页，提示联系管理员 |
| 会话过期       | 重定向到登录页             |

# Desktop Web 重构方案

> 本文档描述 Desktop 客户端 Web 界面的重构方案，参考 Server Web 重构原则。

## 1. 重构核心原则

### 1.1 开发原则

| 原则         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 禁止向后兼容 | 当前处于 v0.2 MVP 阶段，不考虑向后兼容，使用新数据库开发 |
| 禁止单元测试 | 功能验证由人工核验完成，不编写单元测试                   |

### 1.2 对象一致原则

与 Server 保持一致，使用统一的概念模型。

| Headscale 概念 | 重构后概念    | 说明                                   |
| -------------- | ------------- | -------------------------------------- |
| User           | User（用户）  | Agent 和 Client 都是用户，只是角色不同 |
| Node           | Node（设备）  | Agent 设备、Desktop 设备统一管理       |
| Group          | Group（分组） | 用户分组，用于批量授权                 |
| ACL            | ACL（授权）   | 统一的访问控制管理                     |

## 2. 核心概念说明

### 2.1 授权类型

Desktop 用户可以访问的资源分为两类：

| 授权类型 | 说明                                      | 配置位置            | Desktop 展示 |
| -------- | ----------------------------------------- | ------------------- | ------------ |
| 服务授权 | 访问 Agent 上的代理服务（MySQL/Redis 等） | 授权管理 > 服务授权 | 我的服务     |
| SSH 授权 | SSH 登录到 Agent 主机                     | 授权管理 > SSH 授权 | 我的主机     |

### 2.2 我的服务 vs 我的主机

```txt

│                              授权管理                                        │
├─────────────────────────────────────────────────────────────────────────────┤
```

## 4. 我的服务 (Services)

### 4.1 设计说明

- 展示当前用户通过「服务授权」被授权访问的代理服务
- 数据来源：`acl_service_user_permission` + `acl_service_group_permission`
- 服务类型：MySQL、Redis、Web、自定义端口等

### 4.2 数据查询逻辑

```txt
查询用户已授权的服务:
1. 查询 acl_service_user_permission 表，user_id = 当前用户
2. 查询 acl_service_group_permission 表，group_id IN 用户所属分组
3. 合并去重，关联 proxy_service 表获取服务详情
```

### 4.3 列表页 (/services)

```txt

│  我的服务    [共 5 个服务]                                              🔍 搜索  🔄 刷新 │
```

## 5. 我的主机 (Hosts) - 重新设计

### 5.1 设计说明

- 展示当前用户通过「SSH 授权」被授权 SSH 访问的 Agent 主机
- 数据来源：`acl_ssh_user_permission` + `acl_ssh_group_permission`
- 显示内容：主机信息 + 允许使用的 SSH 用户名

### 5.2 数据查询逻辑

```txt
查询用户已授权 SSH 的主机:
1. 查询 acl_ssh_user_permission 表，user_id = 当前用户，enabled = true
2. 查询 acl_ssh_group_permission 表，group_id IN 用户所属分组，enabled = true
3. 合并结果，按 target_user_id (Agent) 分组
4. 关联 user 表获取 Agent 名称，关联 node 表获取隧道 IP
```

### 5.3 列表页 (/hosts)

```txt
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  我的主机    [共 2 台主机]                                              🔍 搜索  🔄 刷新 │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│  ┌─────────────────────────────────┐  ┌─────────────────────────────────┐              │
│  │  🖥️ beagle-beijing              │  │  🖥️ beagle-shanghai             │              │
│  │                                 │  │                                 │              │
│  │  隧道 IP: 100.64.0.33          │  │  隧道 IP: 100.64.0.34          │              │
│  │  SSH 用户: root, deploy        │  │  SSH 用户: deploy               │              │
│  │  状态: 🟢 在线                  │  │  状态: 🔴 离线                  │              │
```

主机卡片字段：

| 字段     | 来源                             | 说明                      |
| -------- | -------------------------------- | ------------------------- |
| 主机名   | user.name                        | Agent 名称                |
| 隧道 IP  | node.ip                          | Agent 的 Tailscale IP     |
| SSH 用户 | acl*ssh*\*\_permission.ssh_users | 允许使用的 SSH 用户名列表 |
| 状态     | Agent 在线状态                   | 在线/离线                 |
| 最后在线 | node.last_heartbeat              | 最后心跳时间              |

## 9. gRPC 接口设计

### 9.1 GetAuthorizedServices - 获取已授权服务

查询用户通过「服务授权」被授权的代理服务。

请求：

| 字段       | 类型   | 说明       |
| ---------- | ------ | ---------- |
| desktop_id | uint64 | Desktop ID |

响应：

| 字段     | 类型                | 说明     |
| -------- | ------------------- | -------- |
| services | []AuthorizedService | 服务列表 |

AuthorizedService：

| 字段        | 类型   | 说明       |
| ----------- | ------ | ---------- |
| id          | string | 服务 ID    |
| name        | string | 服务名称   |
| agent_name  | string | Agent 名称 |
| listen_addr | string | 监听地址   |
| target_addr | string | 目标地址   |
| status      | string | 状态       |

### 9.2 GetAuthorizedHosts - 获取已授权主机（SSH）

查询用户通过「SSH 授权」被授权 SSH 访问的主机。

请求：

| 字段       | 类型   | 说明       |
| ---------- | ------ | ---------- |
| desktop_id | uint64 | Desktop ID |

响应：

| 字段  | 类型             | 说明     |
| ----- | ---------------- | -------- |
| hosts | []AuthorizedHost | 主机列表 |

AuthorizedHost：

| 字段      | 类型     | 说明                  |
| --------- | -------- | --------------------- |
| host_id   | string   | Agent User ID         |
| host_name | string   | Agent 名称            |
| tunnel_ip | string   | 隧道 IP               |
| ssh_users | []string | 允许的 SSH 用户名列表 |
| status    | string   | 在线/离线             |
| last_seen | string   | 最后在线时间          |

## 10. 数据表关系

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│                           Server 数据表                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  user (用户表)                                                              │
│  ├── id, name, role (agent/client), ...                                    │
│                                                                             │
│  node (设备表)                                                              │
│  ├── id, user_id, type (agent/desktop), ip, last_heartbeat, ...           │
│                                                                             │
│  proxy_service (代理服务表)                                                 │
│  ├── id, user_id (Agent), name, source_addr, target_addr, enabled, ...    │
│                                                                             │
│  acl_service_user_permission (服务用户授权)                                 │
│  ├── service_id, user_id (Client)                                          │
│  │   → Client 可访问哪些服务                                               │
│                                                                             │
│  acl_service_group_permission (服务分组授权)                                │
│  ├── service_id, group_id                                                  │
│  │   → 分组可访问哪些服务                                                  │
│                                                                             │
│  acl_ssh_user_permission (SSH 用户授权)                                     │
│  ├── target_user_id (Agent), user_id (Client), ssh_users, enabled         │
│  │   → Client 可 SSH 到哪些 Agent，用哪些用户名                            │
│                                                                             │
│  acl_ssh_group_permission (SSH 分组授权)                                    │
│  ├── target_user_id (Agent), group_id, ssh_users, enabled                 │
│  │   → 分组可 SSH 到哪些 Agent，用哪些用户名                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 11. 新旧对比

| 原设计                      | 新设计                         |
| --------------------------- | ------------------------------ |
| 我的主机 = 所有有服务的主机 | 我的主机 = SSH 授权的主机      |
| 主机下显示服务列表          | 主机下显示 SSH 用户名列表      |
| 查询 proxy_service 表       | 查询 acl*ssh*\*\_permission 表 |
| 点击查看服务                | 点击复制 SSH 命令或直接连接    |

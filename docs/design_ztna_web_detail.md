# ZTNA Web 管理界面详细设计

概要设计见 design_ztna_web.md。本文档是详细设计，覆盖每个页面的原型图、核心业务、核心数据和数据来源、Layout 和组件设计。

## 全局设计规范

### Layout 结构

```
┌─────────────────────────────────────────────────────────────────┐
│  Header（60px）                                                  │
│  Logo | 客户端下载 | 语言切换 | 用户菜单                        │
├──────────┬──────────────────────────────────────────────────────┤
│ Sidebar  │  Main Content                                       │
│ (200px)  │  ┌────────────────────────────────────────────────┐ │
│          │  │ Breadcrumb 面包屑导航                          │ │
│ el-menu  │  ├────────────────────────────────────────────────┤ │
│ 可折叠   │  │                                                │ │
│ 至 64px  │  │ router-view 页面内容                           │ │
│          │  │                                                │ │
│          │  └────────────────────────────────────────────────┘ │
└──────────┴──────────────────────────────────────────────────────┘
```

组件：el-container + el-header + el-aside + el-main

### 导航规范（统一面包屑，禁止返回按钮）

所有详情页统一使用面包屑导航，禁止使用 router.back() 返回按钮。

面包屑层级规则：

```
一级页面（顶级菜单）：
  用户管理

二级页面（子菜单）：
  授权管理 > 服务授权

三级页面（详情页）：
  授权管理 > 服务授权 > 授权详情: postgresql

四级页面（Endpoint 授权详情）：
  授权管理 > SSH 授权 > Endpoint SSH: web-server-1
```

详情页名称通过 ?name=xxx query 参数传递，Breadcrumb 组件从 route.query.name 读取显示。

现有需要修正的页面（去掉返回按钮，改用面包屑）：

| 页面              | 当前导航       | 修正为                                 |
| ----------------- | -------------- | -------------------------------------- |
| Node/Detail       | ArrowLeft 返回 | 面包屑：设备管理 > 设备详情: {name}    |
| Group/Members     | router.back()  | 面包屑：分组管理 > 成员管理: {name}    |
| ACL/ServiceDetail | router.back()  | 面包屑：授权管理 > 服务授权 > 授权详情 |
| ACL/SSHDetail     | router.back()  | 面包屑：授权管理 > SSH 授权 > 授权详情 |
| ACL/UserDetail    | router.back()  | 面包屑：授权管理 > 用户授权 > 授权详情 |
| ACL/GroupDetail   | router.back()  | 面包屑：授权管理 > 分组授权 > 授权详情 |

### 搜索区域统一规范

现有列表页搜索区域存在 4 种不同写法，必须统一。根据筛选条件数量分为两种布局：

简单搜索（筛选条件 ≤ 3 个）：单行布局

```
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│  [筛选1 ▼]  [筛选2 ▼]  [搜索________________🔍]             │
│                                                               │
│                          [重置]  [搜索]        [+ 新建]       │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

复杂搜索（筛选条件 > 3 个）：多行布局

```
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│  筛选1 [▼ 全部]      筛选2 [▼ 全部]      筛选3 [▼ 全部]     │
│  筛选4 [▼ 全部]      搜索  [________________🔍]              │
│                                                               │
│                          [重置]  [搜索]        [+ 新建]       │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

统一尺寸规范：

| 元素           | 规范                                         |
| -------------- | -------------------------------------------- |
| 搜索区域       | el-card shadow="never"，无标题，padding 20px |
| 搜索区域与表格 | margin-bottom: 16px                          |
| 筛选下拉框宽度 | 160px（统一）                                |
| 搜索输入框宽度 | 240px（统一）                                |
| 按钮间距       | 搜索/重置按钮间距 8px                        |
| 新建按钮       | 右对齐，与搜索/重置按钮同行                  |
| 表单项间距     | el-form-item margin-right: 16px              |

统一行为规范：

| 行为     | 规范                                                  |
| -------- | ----------------------------------------------------- |
| 搜索触发 | 点击搜索按钮 或 搜索框回车                            |
| 重置行为 | 清空所有筛选条件 + 重置分页到第 1 页 + 自动触发搜索   |

| 分页布局 | layout="total, sizes, prev, pager, next, jumper"      |
| 默认每页 | 20 条                                                 |
| 页码选项 | [10, 20, 50, 100]                                     |

分组弹窗区别：不需要角色筛选，每行显示分组名 + 成员数，数量 40-50 可一次性加载 + 前端搜索。

各授权类型的"授权参数"区域：

| 授权类型                       | 授权参数区域                                             |
| ------------------------------ | -------------------------------------------------------- |
| 服务授权 / 用户授权 / 分组授权 | 无额外参数（弹窗更紧凑）                                 |
| SSH 授权（Agent + Endpoint）   | Linux 用户：el-select multiple, filterable, allow-create |
|                                | 预设选项: root, autogroup:nonroot，支持自定义输入        |
| K8S 授权（Agent + Endpoint）   | 命名空间：el-select multiple, filterable, allow-create   |
|                                | K8S 角色：el-select filterable, allow-create             |
|                                | 预设选项: admin, developer, viewer                       |
| K8SService 授权 / SVC 跳跃授权 | 命名空间：el-select multiple, filterable, allow-create   |
|                                | Service 模式：el-input，提示: _ 全部，pg_ 前缀匹配       |

通用授权弹窗组件 AuthGrantDialog：

不为每种授权类型写独立弹窗，而是做一个通用组件，通过 Props 区分行为：

| Prop       | 类型   | 说明                                                   |
| ---------- | ------ | ------------------------------------------------------ |
| visible    | bool   | 是否显示                                               |
| title      | string | 弹窗标题                                               |
| targetType | string | "user" 或 "group"（选用户还是选分组）                  |
| paramType  | string | "none" / "ssh" / "k8s" / "k8s-service"（授权参数类型） |
| excludeIds | array  | 已授权的 ID 列表（排除用）                             |
| roleFilter | string | 角色预筛选（"client" / "agent" / 空）                  |

| Event  | 参数                          | 说明     |
| ------ | ----------------------------- | -------- |
| submit | { ids: number[], params: {} } | 提交授权 |
| close  | 无                            | 关闭弹窗 |

弹窗宽度统一 720px。

数据加载策略：

| 对象 | 策略                                                          |
| ---- | ------------------------------------------------------------- |
| 用户 | 远程搜索（输入 2 字符触发 API）+ 分页（每页 10 条）+ 角色筛选 |
| 分组 | 一次性加载全部（数量可控 40-50）+ 前端搜索过滤                |

三个 Tab 的列表结构完全一致，区别仅在于数据来源和跳转的详情页路径不同。

管理员点击"管理授权"进入对应类型的详情页。

#### 核心数据

三个 Tab 分别请求不同 API：

| Tab          | API                      | 详情路径          |
| ------------ | ------------------------ | ----------------- |
| SSH 跳跃授权 | GET /api/v1/acl/jump/ssh | /acl/jump/ssh/:id |

| SVC 跳跃授权 | GET /api/v1/acl/jump/svc | /acl/jump/svc/:id |

| 参数     | 类型   | 说明                      |
| -------- | ------ | ------------------------- |

| search   | string | 按 Endpoint 名称/别名搜索 |
| page     | int    | 页码                      |
| size     | int    | 每页条数                  |

响应字段（三个 Tab 通用）：

| 字段        | 类型   | 说明               |
| ----------- | ------ | ------------------ |
| id          | string | Endpoint ID (UUID) |
| name        | string | Endpoint 名称      |
| alias       | string | 别名               |
| agent_name  | string | 所属 Agent 名称    |
| agent_id    | uint64 | 所属 Agent User ID |

#### 组件设计

# Desktop 登录设计文档

## 1. 概述

本文档描述 Desktop 客户端的登录认证机制和状态存储设计。

**核心功能：**

- 首次登录：使用 Client 凭证（用户名 + 密码）登录
- 再次登录：使用设备令牌（DeviceToken）自动认证
- 隧道连接：登录成功后自动建立 Tailscale 隧道
- 注销：清除本地凭证和隧道状态

**与其他模块的关系：**

| 模块        | 关系                                     |
| ----------- | ---------------------------------------- |
| Server gRPC | 提供 Login、Authenticate、Heartbeat 接口 |
| Headscale   | 提供隧道认证密钥（AuthKey）              |
| 前端 UI     | 提供登录界面和状态展示                   |

**流程说明：**

| 步骤             | 说明                                    |
| ---------------- | --------------------------------------- |
| 创建 gRPC 连接   | 连接到用户指定的 Server 地址            |
| 调用 Login 接口  | 发送用户名、密码、设备指纹、系统信息    |
| Server 验证凭证  | 验证 Client 用户名和密码（bcrypt）      |
| 返回认证信息     | 首次登录返回 secret，用于后续自动认证   |
| 保存 DeviceToken | 格式为 `desktop_id:secret`，存储到本地  |
| 初始化隧道连接   | 使用 auth_key 连接 Headscale 控制服务器 |
| 启动心跳循环     | 定期上报状态，接收已授权服务列表        |

| 认证失败处理        | 清除无效 Token，引导用户重新登录                |

## 3. 状态存储

### 3.1 存储目录结构

所有状态统一存储在 `signaling-desktop` 目录下：

```txt
# Windows
%APPDATA%\signaling-desktop\
├── desktop.json              # App 配置文件
└── tunnel\                   # 隧道状态目录
    └── state.db              # 隧道状态文件

# macOS
~/Library/Application Support/signaling-desktop/
├── desktop.json
└── tunnel\
    └── state.db

# Linux
~/.config/signaling-desktop/
├── desktop.json
└── tunnel\
    └── state.db
```

### 3.2 App 配置文件

**文件路径：** `signaling-desktop/desktop.json`

| 字段   | 类型   | 必填 | 说明                                |
| ------ | ------ | ---- | ----------------------------------- |
| server | string | 是   | Server gRPC 地址                    |
| client | string | 是   | Client 用户名                       |
| token  | string | 否   | 设备令牌（格式：desktop_id:secret） |

**说明：**

- 仅存储必要的 3 个字段，保持精简
- token 为空表示需要重新登录
- 文件权限应设置为 0600（仅用户可读写）

### 3.3 隧道状态文件

**文件路径：** `signaling-desktop/tunnel/state.db`

| 内容           | 说明               |
| -------------- | ------------------ |
| 节点私钥       | 隧道连接的身份密钥 |
| 节点 IP        | 分配的隧道 IP 地址 |
| 控制服务器信息 | Headscale 连接状态 |

**说明：**

- 由隧道引擎自动管理，App 不直接操作
- 注销时可选择是否清除（完全重置 vs 保留节点身份）

### 3.4 目录获取逻辑

| 平台    | 基础目录获取方式     | 完整路径                                          |
| ------- | -------------------- | ------------------------------------------------- |
| Windows | `os.UserConfigDir()` | `%APPDATA%\signaling-desktop`                     |
| macOS   | `os.UserConfigDir()` | `~/Library/Application Support/signaling-desktop` |
| Linux   | `os.UserConfigDir()` | `~/.config/signaling-desktop`                     |

## 4. 异常处理

### 4.1 登录异常

| 异常场景        | 处理方式                       |
| --------------- | ------------------------------ |
| Server 连接失败 | 提示网络错误，允许重试         |
| 用户名不存在    | 提示"用户不存在"               |
| 密码错误        | 提示"认证失败"                 |
| 设备令牌无效    | 清除 Token，引导重新登录       |
| 设备被禁用      | 提示"设备已被禁用"，清除 Token |

### 4.2 隧道异常

| 异常场景         | 处理方式                              |
| ---------------- | ------------------------------------- |
| AuthKey 无效     | 重新获取 AuthKey（调用 Authenticate） |
| 隧道连接超时     | 提示错误，允许手动重连                |
| TUN 设备创建失败 | 提示需要管理员权限                    |
| 隧道断开         | 自动重连，超过阈值后提示用户          |

### 4.3 状态文件异常

| 异常场景         | 处理方式                   |
| ---------------- | -------------------------- |
| 配置文件损坏     | 删除并使用默认配置         |
| 配置目录无写权限 | 提示权限错误               |
| 隧道状态损坏     | 删除状态文件，重新建立连接 |

## 5. 安全设计

### 5.1 凭证安全

| 安全措施        | 说明                                    |
| --------------- | --------------------------------------- |
| 密码不存储      | 密码仅用于首次登录，不保存到本地        |
| Secret 哈希存储 | Server 端使用 bcrypt 存储 Secret 哈希   |
| 文件权限        | 配置文件权限设置为 0600                 |
| 设备绑定        | Secret 与设备指纹绑定，换设备需重新登录 |

### 5.2 传输安全

| 安全措施 | 说明                                  |
| -------- | ------------------------------------- |
| gRPC TLS | 生产环境使用 TLS 加密 gRPC 通信       |
| 隧道加密 | Tailscale 使用 WireGuard 加密隧道流量 |

## 6. 接口依赖

### 6.1 gRPC 接口

| 接口         | 用途     | 调用时机                  |
| ------------ | -------- | ------------------------- |
| Login        | 首次登录 | 用户输入密码登录          |
| Authenticate | 设备认证 | 使用 DeviceToken 自动登录 |
| Heartbeat    | 心跳上报 | 登录成功后持续调用        |

### 6.2 Login 请求字段

| 字段               | 类型   | 说明                         |
| ------------------ | ------ | ---------------------------- |
| client_name        | string | Client 用户名                |
| client_secret      | string | Client 密码                  |
| device_name        | string | 设备名称（主机名）           |
| device_fingerprint | string | 设备指纹哈希                 |
| system_info        | object | 系统信息（OS、版本、CPU 等） |

### 6.3 Login 响应字段

| 字段       | 类型   | 说明                       |
| ---------- | ------ | -------------------------- |
| success    | bool   | 是否成功                   |
| message    | string | 响应消息                   |
| desktop_id | uint64 | Desktop ID                 |
| secret     | string | 设备密钥（仅首次登录返回） |
| auth_key   | string | 隧道认证密钥               |
| server_url | string | 隧道控制服务器地址         |

### 6.4 Authenticate 请求字段

| 字段               | 类型   | 说明         |
| ------------------ | ------ | ------------ |
| desktop_id         | uint64 | Desktop ID   |
| secret             | string | 设备密钥     |
| device_fingerprint | string | 设备指纹哈希 |
| system_info        | object | 系统信息     |

### 6.5 Authenticate 响应字段

| 字段       | 类型   | 说明               |
| ---------- | ------ | ------------------ |
| success    | bool   | 是否成功           |
| message    | string | 响应消息           |
| auth_key   | string | 隧道认证密钥       |
| server_url | string | 隧道控制服务器地址 |

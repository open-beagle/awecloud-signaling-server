# 前端设计规范

本文档定义 Web 管理界面的统一设计规范，所有页面必须遵循此规范。

---

## 一、框架布局

### 1.1 整体结构

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│  Header（顶部导航栏）                                          height: 60px │
├────────────┬────────────────────────────────────────────────────────────────┤
│            │                                                                │
│  Sidebar   │  Main（主体内容区）                                            │
│  （左侧    │                                                                │
│   菜单）   │  ┌─ Breadcrumb（面包屑导航）────────────────────────────────┐  │
│            │  │  首页 / 代理管理                          margin-bottom: 16px│
│  width:    │  └──────────────────────────────────────────────────────────┘  │
│  200px     │                                                                │
│  (折叠64px)│  ┌─ Content（页面内容）────────────────────────────────────┐  │
│            │  │                                                          │  │
│            │  │  el-card 或其他内容                                      │  │
│            │  │                                                          │  │
│            │  └──────────────────────────────────────────────────────────┘  │
│            │                                                                │
│            │                                              padding: 20px     │
└────────────┴────────────────────────────────────────────────────────────────┘
```

### 1.2 布局尺寸规范

| 区域       | 属性          | 值                          |
| ---------- | ------------- | --------------------------- |
| Header     | height        | 60px                        |
| Header     | padding       | 0 20px                      |
| Header     | background    | #ffffff                     |
| Header     | border-bottom | 1px solid #e4e7ed           |
| Sidebar    | width         | 200px（展开）/ 64px（折叠） |
| Sidebar    | background    | #ffffff                     |
| Sidebar    | border-right  | 1px solid #e4e7ed           |
| Main       | padding       | 20px                        |
| Main       | background    | #f0f2f5                     |
| Breadcrumb | margin-bottom | 16px                        |

### 1.3 响应式适配

| 屏幕宽度 | Main padding |
| -------- | ------------ |
| > 768px  | 20px         |
| ≤ 768px  | 12px         |

## 二、列表页面结构

### 2.1 标准布局

列表页面放在 Main 区域的 Content 中，使用 el-card 包裹：

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│  页面标题                                                    [+ 创建按钮]   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─ 筛选栏 ─────────────────────────────────────────────────────────────┐   │
│  │  [下拉筛选1]  [下拉筛选2]  [🔍 搜索框________]                       │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─ 数据表格 ───────────────────────────────────────────────────────────┐   │
│  │  ID    名称      字段2      字段3      状态      操作                │   │
│  │  ───────────────────────────────────────────────────────────────────  │   │
│  │  1     xxx       xxx        xxx        🟢运行    [按钮] [按钮]       │   │
│  │  2     xxx       xxx        xxx        🔴停止    [按钮] [按钮]       │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 页面容器样式

页面组件**不需要**设置外层 padding，因为 Layout 的 `layout-main` 已经设置了 `padding: 20px`。

```css
/* ❌ 错误：不要设置 padding */
.xxx-container {
  padding: 20px;
}

/* ✅ 正确：不设置 padding，或只设置 width */
.xxx-container {
  width: 100%;
}
```

### 2.3 必须元素

| 元素     | 位置         | 说明                      |
| -------- | ------------ | ------------------------- |
| 页面标题 | 卡片头部左侧 | 使用 i18n 国际化          |
| 创建按钮 | 卡片头部右侧 | 带 Plus 图标              |
| 筛选栏   | 表格上方     | 使用 flex 布局，gap: 12px |
| 数据表格 | 主体区域     | 使用 el-table，带 stripe  |
| 操作列   | 表格最右侧   | fixed="right"             |

## 三、卡片头部规范

### 3.1 标准结构

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│  {{ $t('xxx.title') }}                                   [+ 创建/添加]      │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 样式规范

| 属性     | 值                                                                 |
| -------- | ------------------------------------------------------------------ |
| 布局     | display: flex; justify-content: space-between; align-items: center |
| 标题字号 | 默认（继承 el-card）                                               |
| 按钮类型 | type="primary"                                                     |
| 按钮图标 | Plus 图标在文字前                                                  |

## 四、筛选栏规范

### 4.1 标准结构

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│  [下拉筛选1 ▼]  [下拉筛选2 ▼]  [🔍 搜索关键词________]                      │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 设计原则

| 原则     | 说明                               |
| -------- | ---------------------------------- |
| 即时筛选 | 选择后立即筛选，无需点击"查询"按钮 |
| 前端过滤 | 数据量小时使用 computed 前端过滤   |
| 清除选项 | 所有筛选器必须支持 clearable       |
| 默认选项 | 第一个选项为"全部 xxx"             |

### 4.3 样式规范

| 属性       | 值                               |
| ---------- | -------------------------------- |
| 布局       | display: flex; gap: 12px         |
| 下拉框宽度 | 根据内容自适应，或固定 150-200px |
| 搜索框宽度 | 200px                            |
| 下边距     | margin-bottom: 16px              |

### 4.4 禁止事项

| 禁止              | 说明                         |
| ----------------- | ---------------------------- |
| ❌ 查询/重置按钮  | 使用即时筛选，不需要手动触发 |
| ❌ el-form inline | 直接使用 div + flex 布局     |
| ❌ label 标签     | 筛选器使用 placeholder 说明  |

## 五、数据表格规范

### 5.1 标准结构

```txt
┌─────────────────────────────────────────────────────────────────────────────┐
│  ID    名称        字段2        字段3        状态      操作                 │
│  ───────────────────────────────────────────────────────────────────────────│
│  1     名称链接    内容         内容         🟢标签    [按钮] [按钮]        │
│  2     名称链接    内容         内容         🔴标签    [按钮] [按钮]        │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 表格属性

| 属性      | 值      | 说明           |
| --------- | ------- | -------------- |
| stripe    | true    | 斑马纹         |
| v-loading | loading | 加载状态       |
| border    | 不使用  | 不使用边框样式 |

### 5.3 列规范

| 列类型   | 宽度            | 说明                            |
| -------- | --------------- | ------------------------------- |
| ID       | width="80"      | 固定宽度                        |
| 名称     | min-width="120" | 可点击跳转详情                  |
| 普通字段 | min-width="xxx" | 根据内容设置                    |
| 状态     | width="100"     | 使用 el-tag                     |
| 操作     | width="xxx"     | fixed="right"，根据按钮数量设置 |

### 5.4 名称列规范

名称列应可点击跳转到详情页，使用 el-link：

| 属性      | 值      |
| --------- | ------- |
| type      | primary |
| underline | false   |

### 5.5 状态列规范

使用 el-tag 显示状态：

| 状态              | type    | 颜色 |
| ----------------- | ------- | ---- |
| running / online  | success | 绿色 |
| stopped / offline | info    | 灰色 |
| error             | danger  | 红色 |
| warning           | warning | 橙色 |

### 5.6 操作列规范

| 场景            | 按钮样式               |
| --------------- | ---------------------- |
| 操作少（≤3 个） | 文字按钮，size="small" |
| 操作多（>3 个） | 图标按钮 + el-tooltip  |

## 七、国际化规范

### 7.1 必须国际化的内容

| 内容        | 说明                                    |
| ----------- | --------------------------------------- |
| 页面标题    | $t('xxx.title')                         |
| 按钮文字    | $t('xxx.create')、$t('common.delete')   |
| 表格列标题  | :label="$t('xxx.name')"                 |
| placeholder | :placeholder="$t('xxx.placeholder')"    |
| 状态文字    | getStatusText() 返回 $t()               |
| 提示消息    | ElMessage.success($t('common.success')) |

### 7.2 公共 key

| key            | 中文     | 英文    |
| -------------- | -------- | ------- |
| common.actions | 操作     | Actions |
| common.status  | 状态     | Status  |
| common.create  | 创建     | Create  |
| common.edit    | 编辑     | Edit    |
| common.delete  | 删除     | Delete  |
| common.start   | 启动     | Start   |
| common.stop    | 停止     | Stop    |
| common.save    | 保存     | Save    |
| common.cancel  | 取消     | Cancel  |
| common.confirm | 确认     | Confirm |
| common.success | 操作成功 | Success |
| common.failed  | 操作失败 | Failed  |

## 八、禁止事项汇总

| 禁止项                 | 说明               | 替代方案         |
| ---------------------- | ------------------ | ---------------- |
| ❌ el-form inline 筛选 | 增加不必要的复杂度 | 使用 div + flex  |
| ❌ 查询/重置按钮       | 用户体验差         | 即时筛选         |
| ❌ 筛选器 label        | 占用空间           | 使用 placeholder |
| ❌ el-table border     | 视觉效果差         | 使用 stripe      |
| ❌ 硬编码中文          | 不支持国际化       | 使用 $t()        |

# Tailscale 升级 - Server Web 变更设计

> 本文档描述 Tailscale 升级后 Server Web 管理界面的变更，包括菜单结构调整和各模块的业务变化。

## 1. 菜单结构变更

### 1.1 变更前菜单

```txt
├── 代理管理 (Agents)
├── 服务管理
│   ├── STCP实例
│   ├── STCP访问
│   └── TCP实例
├── 客户管理 (Clients)
├── 分组管理 (Groups)
├── 收藏管理 (Favorites)
├── 审计日志 (Audit Logs)
└── 系统配置 (System Config)
```

### 1.2 变更后菜单

```txt
├── 代理管理 (Agents)           ← 新增字段：Tailscale IP、分组(文本)、Services 数量
├── 服务管理 (Services)         ← 服务列表（端口映射）
│   ├── 桌面授权               ← Desktop 访问服务的授权管理
│   └── Agent授权              ← Agent 访问其他 Agent 服务的授权管理
├── 客户管理 (Clients)          ← 新增字段：Tailscale IP
├── 分组管理 (Groups)           ← 保持不变（Client 分组）
├── 收藏管理 (Favorites)        ← 保持不变
├── 审计日志 (Audit Logs)       ← 保持不变
└── 系统配置 (System Config)    ← 新增 Tailscale 配置项
```

### 1.3 菜单变更说明

| 菜单     | 变更类型 | 说明                                       |
| -------- | -------- | ------------------------------------------ |
| 代理管理 | 修改     | 新增 Tailscale IP、分组、Services 字段     |
| 服务管理 | 修改     | 新增子菜单：服务列表、桌面授权、Agent 授权 |
| 客户管理 | 修改     | 新增 Tailscale IP 字段                     |
| 分组管理 | 保持     | 无变化（Client 分组）                      |
| 收藏管理 | 保持     | 无变化                                     |
| 审计日志 | 保持     | 无变化                                     |
| 系统配置 | 修改     | 新增 Tailscale/Headscale 配置项            |

## 2. 代理管理 (Agents)

### 2.1 变更概述

Agent 升级后内置 Tailscale 客户端，每个 Agent 获得一个 Tailscale IP，并可以创建多个端口映射服务。

### 2.2 列表字段变更

| 字段         | 变更前 | 变更后 | 说明                           |
| ------------ | ------ | ------ | ------------------------------ |
| ID           | ✓      | ✓      | 保持                           |
| 名称         | ✓      | ✓      | 保持                           |
| 所属 Agent   | ✓      | -      | 移除（本身就是 Agent 列表）    |
| 状态         | ✓      | ✓      | 保持                           |
| 版本         | ✓      | ✓      | 保持                           |
| 最后在线     | ✓      | ✓      | 保持                           |
| Tailscale IP | -      | ✓      | 新增，如 100.64.0.10           |
| 分组         | -      | ✓      | 新增，可直接编辑，默认为空     |
| Services     | -      | ✓      | 新增，端口映射数量，可点击跳转 |

## 3. 服务管理 (Services)

### 3.1 子菜单结构

```txt
服务管理 (Services)
├── 服务列表        → /services              统一的端口映射列表
├── 桌面授权        → /services/desktop-auth  Desktop 访问服务的授权管理
└── Agent授权       → /services/agent-auth    Agent 访问其他 Agent 服务的授权管理
```

### 3.2 变更概述

原有的 STCP 实例、STCP 访问、TCP 实例 三个子菜单重新组织为：

- **服务列表**：统一的端口映射管理
- **桌面授权**：Desktop（Client）访问服务的权限管理
- **Agent 授权**：Agent 访问其他 Agent 服务的权限管理

### 3.3 概念对比

| 变更前    | 变更后     | 说明                       |
| --------- | ---------- | -------------------------- |
| STCP 实例 | 服务列表   | Agent 监听端口，转发到内网 |
| STCP 访问 | 桌面授权   | Desktop 访问服务的权限管理 |
| TCP 实例  | 服务列表   | 合并到统一的服务管理       |
| -         | Agent 授权 | 新增，Agent 间访问权限管理 |

## 3B. 桌面授权 (/services/desktop-auth)

> 参考：[Tailscale 多租户安全设计](design_tailscale_security.md)

### 3B.1 功能说明

管理 Desktop（Client）访问服务的权限：

## 3D. 数据模型变更

新建 `proxy_service` 表替代原有的 `stcp_instance` 和 `tcp_service` 表：

| 字段        | 类型   | 说明                            |
| ----------- | ------ | ------------------------------- |
| id          | int    | 主键                            |
| name        | string | 服务名称                        |
| agent_id    | int    | 所属 Agent ID                   |
| listen_port | int    | 监听端口                        |
| target_addr | string | 目标地址，如 192.168.1.100:3306 |
| status      | string | 状态：running / stopped / error |
| connections | int    | 当前连接数                      |
| bytes_in    | int64  | 入站流量（字节）                |
| bytes_out   | int64  | 出站流量（字节）                |
| access_type | string | 访问类型：public/private/group  |
| owner_id    | int    | 创建者 Client ID                |
| group_id    | int    | 所属 Client 组 ID（可空）       |
| remark      | string | 备注                            |
| created_at  | time   | 创建时间                        |
| updated_at  | time   | 更新时间                        |

新建 `service_permission` 表 - Desktop 额外授权（参考 [Tailscale 多租户安全设计](design_tailscale_security.md)）：

| 字段       | 类型 | 说明               |
| ---------- | ---- | ------------------ |
| id         | int  | 主键               |
| service_id | int  | 服务 ID            |
| client_id  | int  | 被授权的 Client ID |
| granted_by | int  | 授权人（Admin ID） |
| granted_at | time | 授权时间           |
| expires_at | time | 过期时间（可空）   |
| created_at | time | 创建时间           |

新建 `agent_service_permission` 表 - Agent 访问授权：

| 字段       | 类型 | 说明               |
| ---------- | ---- | ------------------ |
| id         | int  | 主键               |
| agent_id   | int  | 访问方 Agent ID    |
| service_id | int  | 被访问的服务 ID    |
| granted_by | int  | 授权人（Admin ID） |
| granted_at | time | 授权时间           |
| created_at | time | 创建时间           |

### 3.7 API 变更

| 变更前 API                    | 变更后 API                  | 说明            |
| ----------------------------- | --------------------------- | --------------- |
| GET /api/v1/stcp/instances    | GET /api/v1/services        | 获取服务列表    |
| POST /api/v1/stcp/instances   | POST /api/v1/services       | 创建服务        |
| DELETE /api/v1/stcp/instances | DELETE /api/v1/services/:id | 删除服务        |
| GET /api/v1/stcp/visitors     | -                           | 移除            |
| GET /api/v1/tcp/services      | -                           | 合并到 services |

## 6. 路由变更

### 6.1 变更前路由

```txt
/agents                    → Agent 列表
/services/stcp             → STCP 实例列表
/services/stcp-visitors    → STCP 访问列表
/services/tcp              → TCP 实例列表
/clients                   → 客户端列表
/groups                    → 分组列表
/favorites                 → 收藏列表
/audit-logs                → 审计日志
/system/config             → 系统配置
```

### 6.2 变更后路由

```txt
/agents                    → Agent 列表（含分组管理）
/agents/:id                → Agent 详情（含端口映射服务）
/services                  → 服务列表
/services/desktop-auth     → 桌面授权
/services/agent-auth       → Agent授权
/clients                   → 客户端列表
/groups                    → 分组列表（Client 分组）
/favorites                 → 收藏列表
/audit-logs                → 审计日志
/system/config             → 系统配置
```

### 6.3 移除的路由

| 路由                      | 原用途        | 移除原因                        |
| ------------------------- | ------------- | ------------------------------- |
| /services/stcp            | STCP 实例     | 合并到 /services                |
| /services/stcp-visitors   | STCP 访问     | Desktop 直接通过 Tailscale 访问 |
| /services/tcp             | TCP 实例      | 合并到 /services                |
| /services/stcp/:id/access | STCP 访问控制 | 通过 Headscale ACL 控制         |

## 8. 迁移说明

### 8.1 数据迁移

| 原表          | 新表          | 迁移方式                        |
| ------------- | ------------- | ------------------------------- |
| stcp_instance | proxy_service | 字段映射迁移                    |
| tcp_service   | proxy_service | 字段映射迁移                    |
| stcp_visitor  | -             | 不迁移，Desktop 直接访问        |
| stcp_access   | -             | 不迁移，通过 Headscale ACL 控制 |

### 8.2 兼容性

- 迁移期间保留原有 API，标记为 deprecated
- 新 API 与旧 API 并行运行 1-2 个版本
- 前端优先使用新 API，降级使用旧 API

# Server Web 管理界面设计

> 本文档描述 Server Web 管理界面的最终设计，包括菜单结构、界面布局和页面模型。

## 1. 菜单结构

```txt
├── 代理管理 (Agents)
├── 服务管理 (Services)
│   ├── 桌面授权
│   └── 代理授权
├── 客户管理 (Clients)
├── 分组管理 (Groups)
│   ├── 用户分组
│   └── 代理分组
├── 审计日志 (Audit Logs)
└── 系统配置 (System Config)
```

---

| 连接时间 | 实时查询 | 访问页面时向 Agent 请求               | 日期时间   |

说明：点击 [刷新] 按钮重新向 Agent 请求网络信息和隧道信息

端口映射表格模型：

| 字段     | 来源              | 获取方式                        | 展示类型   |

端口访问表格模型：

| -------- | ----------------- | ------------------------------- | ---------- |

| 别名     | port_forward 表   | 关联查询 alias                  | 文本       |

| 监听地址 | port_forward 表   | 关联查询 listen_addr            | 文本       |

| 字段     | 来源              | 获取方式                                                    | 展示类型     |
| -------- | ----------------- | ----------------------------------------------------------- | ------------ |
| ID       | proxy_service 表  | 主查询 uuid                                                 | 文本         |
| 服务名称 | proxy_service 表  | 主查询 name                                                 | 文本         |
| 所属Agent| 关联查询          | JOIN agent ON agent.id = proxy_service.agent_id             | 文本         |

| 分组     | 关联统计          | COUNT(service_group_permission) WHERE group_type='client'   | 数字，可点击 |
| 用户     | 关联统计          | COUNT(service_client_permission)                            | 数字，可点击 |

# Server Web 管理界面设计

> 本文档描述 Server Web 管理界面的最终设计，包括菜单结构、界面布局和页面模型。

## 1. 菜单结构

```txt
├── 代理管理 (Agents)
├── 服务管理 (Services)
│   ├── 桌面授权
│   └── 代理授权
├── 客户管理 (Clients)
├── 分组管理 (Groups)
│   ├── 用户分组
│   └── 代理分组
├── 隧道管理 (Tunnel)
│   ├── User 管理
│   ├── Node 管理
│   └── ACL 管理
├── 审计日志 (Audit Logs)
└── 系统配置 (System Config)
```

> 隧道管理详细设计参见 [隧道管理设计](design_tunnel_management.md)

### 2.3 创建本地服务对话框

```txt
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  创建本地服务                                                              [X]          │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│  * 服务名称                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────────┐   │
│  │  ssh                                                                             │   │
│  └─────────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                         │
│  别名                                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────────────┐   │
│  │  内网 Web服务                                                                    │   │
│  └─────────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                         │
│  * 源地址                                                                               │
│  ┌──────────────────────────────────┬──────────────────────────────────────────────┐   │
│  │  100.64.0.9                      │  :  2222                                     │   │
│  └──────────────────────────────────┴──────────────────────────────────────────────┘   │
│    VPN IP（自动填充）                    源端口                                        │
│                                                                                         │
│  ⓘ 内网中，在保证端口不冲突的情况下，可以使用相同的源端口                               │
│                                                                                         │
│  * 目标地址                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────────┐   │
│  │  127.0.0.1:22                                                                    │   │
│  └─────────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                         │
│  ⓘ 本机内网IP地址和端口                                                                 │
│                                                                                         │
│                                                              [取消]  [创建]             │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

表单字段说明：

| 字段     | 类型     | 必填 | 说明                                                   | 验证规则                     |
| -------- | -------- | ---- | ------------------------------------------------------ | ---------------------------- |
| 服务名称 | 文本输入 | 是   | 服务的唯一标识，用于生成完整服务名（agent_name/name） | 字母、数字、下划线、中划线   |
| 别名     | 文本输入 | 否   | 服务的显示名称，便于识别                               | 任意字符，最长 50 字符       |
| VPN IP   | 只读显示 | -    | 自动填充 Agent 的隧道 IP                               | -                            |
| 源端口   | 数字输入 | 是   | 在 VPN 网络中监听的端口                                | 1-65535，不能与已有服务冲突  |
| 目标地址 | 文本输入 | 是   | 内网中实际服务的地址，格式：IP:端口                    | 必须是有效的 IP:端口格式     |

表单验证：

- 服务名称：不能与该 Agent 下已有服务重复
- 源端口：不能与该 Agent 下已有本地服务的源端口冲突
- 目标地址：必须是有效的 IP:端口格式（支持 IPv4 和 IPv6）

创建成功后：

- 服务状态初始为 `pending`（等待 Agent 启动）
- Agent 收到通知后启动服务，状态变为 `running`
- 如果启动失败，状态变为 `error`，显示错误信息

│                                                                                         │

表单字段说明：

| 字段       | 类型     | 必填 | 说明                        | 验证规则                                  |
| ---------- | -------- | ---- | --------------------------- | ----------------------------------------- |
| 远程 Agent | 下拉选择 | 是   | 选择要访问的远程 Agent      | 只显示在线的 Agent，排除当前 Agent 自己   |
| 远程服务   | 下拉选择 | 是   | 选择远程 Agent 上的本地服务 | 只显示 running 状态的服务                 |
| 本地网卡   | 下拉选择 | 是   | 选择本地网卡，用于监听端口  | 从 Agent 网络信息中获取                   |
| 源端口     | 数字输入 | 是   | 在本地网卡上监听的端口      | 1-65535，不能与已有服务在同一网卡上冲突   |

下拉选择显示格式：

- **远程 Agent**：`name (alias)` 或 `name`（如果 alias 为空）
  - 示例：`beijing (北京机房)` 或 `beijing`
- **远程服务**：`name (alias)` 或 `name`（如果 alias 为空）
  - 示例：`mysql (MySQL数据库)` 或 `mysql`
- **本地网卡**：`interface: ip`
  - 示例：`eth0: 192.168.1.100`

表单验证：

- 远程服务：不能选择已经创建过转发的服务（避免重复）
- 源端口：不能与该 Agent 下已有远程服务在同一网卡上的源端口冲突

创建成功后：

- 服务名称自动生成为：`remote_agent_name/service_name`（例如：`beijing/mysql`）
- 服务状态初始为 `pending`（等待 Agent 启动）
- Agent 收到通知后启动端口转发，状态变为 `running`
- 如果启动失败，状态变为 `error`，显示错误信息

错误状态时，鼠标悬停显示错误信息（error_msg 字段）

远程服务表格模型：

| 字段     | 来源            | 获取方式                              | 展示类型 |
| -------- | --------------- | ------------------------------------- | -------- |
| 名称     | 关联查询        | agent.name + "/" + proxy_service.name | 文本     |
| 别名     | 关联查询        | proxy_service.alias                   | 文本     |
| 源地址   | port_forward 表 | 关联查询 source_addr                  | 文本     |
| 目标地址 | port_forward 表 | 关联查询 target_addr                  | 文本     |
| 状态     | port_forward 表 | 关联查询 status                       | 状态标签 |

远程服务状态说明：

| 状态值   | 显示    | 说明                             | 可用操作         |
| -------- | ------- | -------------------------------- | ---------------- |
| running  | 🟢 运行 | 服务正常运行中                   | 禁用、编辑、删除 |
| disabled | ⚫ 禁用 | 服务已禁用                       | 启用、编辑、删除 |
| error    | 🔴 错误 | 启动失败（如网卡丢失、端口占用） | 重试、编辑、删除 |
| pending  | 🟡 等待 | 等待 VPN 就绪后启动              | 禁用、编辑、删除 |

错误状态时，鼠标悬停显示错误信息，常见错误：

- `PORT_IN_USE`: 端口被占用
- `NETWORK_INTERFACE_LOST`: 配置的网段未找到可用 IP
- `TARGET_UNREACHABLE`: 目标服务不可达
- `ACL_DENIED`: 权限不足
